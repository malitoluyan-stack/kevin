# TaskFlow Inbox Triage — 收件箱分类处理

对输入的任务列表、邮件、消息或 GitHub issues 进行快速分类和优先级排序。

## 输入来源（通过 `$ARGUMENTS` 指定）

| 来源 | 说明 |
|------|------|
| `text <content>` | 直接粘贴文本列表 |
| `file <path>` | 读取文件中的任务列表 |
| `github-issues` | 从当前仓库拉取 open issues |
| `clipboard` | 处理粘贴的内容 |

## 分类框架（艾森豪威尔矩阵）

| | 紧急 | 不紧急 |
|--|------|-------|
| **重要** | 🔴 立即做 | 🟡 计划做 |
| **不重要** | 🟠 委派 | ⚪ 删除/搁置 |

## 行为

1. 解析所有输入条目
2. 对每条进行评估：
   - **紧急度**：有 deadline/阻塞他人/已逾期
   - **重要度**：影响核心目标/高价值/不可逆
3. 分配四象限标签
4. 输出分类结果 + 建议的执行顺序

## 输出

```
🔴 立即做（今天）
  1. [任务] — 原因：阻塞他人

🟡 计划做（本周）
  2. [任务] — 建议：周三前

🟠 委派/简化
  3. [任务] — 建议：交给X处理

⚪ 搁置
  4. [任务] — 原因：低价值
```

完成后可一键推送到 `/taskflow new`。
