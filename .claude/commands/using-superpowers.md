# Using Superpowers

Before starting any task, clarify the following with the user:

1. **Goal** — What is the desired end state? What does success look like?
2. **Boundaries** — What is out of scope? Any constraints (tech stack, time, budget)?
3. **Acceptance criteria** — How will we know the task is done correctly? What are the tests or checks?

Ask these as a short numbered list. Do not begin execution until the user has confirmed or answered. If any answers are unclear, ask a follow-up before proceeding.

Once all three are confirmed, summarize them back in one paragraph, then begin.
