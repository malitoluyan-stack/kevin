# Brainstorming

The user has a rough idea. Your job is to turn it into **2–3 concrete, distinct options** before any implementation begins.

For each option provide:
- **Name** — a short label
- **Approach** — one sentence on how it works
- **Best for** — the scenario where this option wins
- **Trade-off** — the main downside

End with a recommendation and ask the user to pick one (or describe a different direction) before you write any code or take any action.

Do not merge options or hedge. Keep each option clearly separate.
