# Pharmacoeconomics — 药物经济学分析

执行药物经济学评估，支持药品准入、医保谈判和临床决策。使用 `$ARGUMENTS` 指定分析对象。

## 格式：`<药物A> vs <药物B或标准治疗> <适应症> [视角：医保/医院/患者/社会]`

## 分析方法

### 成本效益分析（CEA）
- 增量成本效果比（ICER）= ΔCost / ΔEffect
- 效果指标：QALY（质量调整生命年）/ LYG（生命年增益）
- WTP阈值：中国 = 3×人均GDP（约¥31万/QALY，2026年参考值）

### 成本效用分析（CUA）
- 健康效用值来源：EQ-5D / SF-6D 测量
- 效用权重：中国本土化数据（TTO法）

### 成本最小化分析（CMA）
适用于疗效已证明等效的情况（仿制药 vs 原研）

### 预算影响分析（BIA）
- 目标人群规模 × 治疗方案市场份额 × 净成本
- 滚动3–5年预算影响

## 输出格式

```
ICER 结果：¥XXX,XXX / QALY
与WTP阈值对比：优势/劣势/临界
敏感性分析：单因素/概率性（龙卷风图数据）
结论：从[医保/医院]视角，该药品[建议/不建议]纳入
```

## 数据来源标注要求
所有成本数据须注明来源（DRG费率/省级招标价/零售价）和时间点。
