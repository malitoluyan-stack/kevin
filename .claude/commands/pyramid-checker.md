# Pyramid Checker — 金字塔原理幻灯片审查

对咨询交付物执行金字塔原理合规检查。使用 `$ARGUMENTS` 指定文件路径或直接粘贴幻灯片标题列表。

## 检查维度

### 1. 标题信息性（最高权重）
每条标题必须是**结论**，而非**主题**：
- ❌ "认知度调查" → ✅ "仅20%公众了解X，远低于行业均值"
- ❌ "市场分析" → ✅ "中国AI医疗市场2026年将突破千亿，增速全球第一"
- ❌ "战略建议" → ✅ "建议优先进入华南市场，ROI领先其他区域40%"

### 2. 故事线完整性
将所有幻灯片标题按顺序连读，检查：
- 是否构成完整论证链（情境→冲突→解决方案）
- 是否存在逻辑跳跃（两个相邻标题之间读者无法自然推断）
- 是否有多余页（删去后故事线不受影响）

### 3. 单页概念聚焦
- 一页只传达一个核心观点
- 若页内出现两部分内容，必须有显式逻辑连接词（"但是" / "因此" / "→"）
- 检查每页是否满足三者之一：传达关键事实 / 完成逻辑承接 / 提出推荐

### 4. 受众中心审查
对每页问："若删去此页，决策者的判断会改变吗？"
- 不改变 → 标记为可删除
- 改变 → 保留

## 输出格式

```
第 N 页 — "[原标题]"
问题：主题型标题（未写结论）
建议："[改写后的信息性标题]"
故事线缺口：与第 N-1 页之间缺少逻辑连接词
```

总结：信息性标题占比 X%，故事线断点 N 处，建议删除 N 页。
