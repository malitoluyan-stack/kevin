# 五年规划文风 — Chinese Five-Year Development Plan Style

按照中国国民经济和社会发展五年规划（国家/省/市/行业/企业）的标准文风起草文稿。使用 `$ARGUMENTS` 指定规划层级、领域和规划期。

## 格式：`<层级：国家/省/市/行业/企业> <规划名称> <规划期：如2026-2030> <核心目标>`

---

## 文体特征（必须严格遵守）

### 标准结构（国家/省级）

```
第一章  发展基础与形势
  第一节  "十X五"时期发展成就
  第二节  发展环境分析（机遇与挑战）

第二章  指导思想、基本原则与发展目标
  第一节  指导思想
  第二节  基本原则（通常4–6条，每条有标题）
  第三节  主要目标（含量化指标表）

第三至N章  重点任务与重大工程
  [按领域分章]

第N+1章  保障措施
  （体制机制/财政金融/人才科技/组织实施）
```

### 语言特征

**开篇定性句式**：
「"十X五"时期（XXXX—XXXX年）是[历史方位定性]的关键五年。」
示例：「"十五五"时期（2026—2030年）是我国全面建成社会主义现代化强国、实现第二个百年奋斗目标的重要时期。」

**指导思想标准句式**：
「以习近平新时代中国特色社会主义思想为指导，全面贯彻党的[X届X中全会]精神，坚持[政策主线1]、[政策主线2]……」

**基本原则写法（四字标题+阐述）**：
- 「坚持党的全面领导」
- 「坚持以人民为中心」
- 「坚持创新驱动发展」
- 「坚持高水平对外开放」

**目标指标表格标准格式**：

| 指标 | 单位 | [基期值] | [规划期目标] | 属性 |
|------|------|---------|------------|------|
| GDP增速 | % | X | [X] | 预期性 |
| 研发经费投入强度 | % | X | [X] | 预期性 |
| 单位GDP能耗降低 | % | — | [X] | 约束性 |

属性分类：
- **预期性**：政府引导方向，非强制要求
- **约束性**：政府须确保完成，有问责机制

**重点任务句式**：
「深入实施[战略名称]，[动词]推进[具体工作]，到[年份]，[量化目标]。」

**重大工程/专项写法**：
「实施[工程名称]工程。[工程内容简述]。[预期产出或覆盖范围]。」

---

## 关键术语库（按十五五时期政策方向）

**经济发展**：新质生产力、现代化产业体系、数字经济、实体经济、专精特新

**科技创新**：科技自立自强、关键核心技术攻关、创新链产业链资金链人才链融合

**绿色发展**：碳达峰碳中和、绿色低碳转型、生态文明建设

**对外开放**：高水平对外开放、共建「一带一路」、自贸区/港建设

**民生保障**：共同富裕、公共服务均等化、社会治理现代化

**AI/数字化**：数字中国、人工智能赋能、数据要素市场化、算力基础设施

## 企业五年规划适配版

企业版保留规划文风的庄重感，同时适配商业语境：

- 「指导思想」→「战略指引」（可引用企业使命愿景）
- 「约束性指标」→「承诺指标」（KPI保底值）
- 「预期性指标」→「目标指标」（努力方向）
- 「重大工程」→「战略举措」或「重点项目」
- 章节编号改为阿拉伯数字（1. 2. 3.）

适合用于：
- 国有企业向主管部门提交的发展规划
- 上市公司战略白皮书（体现政策对齐）
- 大型民营企业对政府合作方的战略承诺文件

---

## 输出格式

完整规划草稿，含：
1. 目录（章节结构）
2. 正文各章（含指标表）
3. 重大工程/专项清单
4. 保障措施章节

字数参考：国家级约30,000字，省级约20,000字，市级约15,000字，企业级约8,000字。

配合 `/gov-work-report-style`、`/consulting-slide-generator`、`/powerpoint-pptx-cn` 可形成完整交付物。
