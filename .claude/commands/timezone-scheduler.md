# Timezone Scheduler — 多时区日程协调

协调旧金山、上海、香港、青岛四地会议时间，生成日程建议。使用 `$ARGUMENTS` 描述会议需求。

## 时区配置（已预设）

| 城市 | 时区 | 夏令时 |
|------|------|--------|
| 旧金山 | UTC-8（冬）/ UTC-7（夏，3月第2周日–11月第1周日） | 是 |
| 上海 | UTC+8 | 否 |
| 香港 | UTC+8 | 否 |
| 青岛 | UTC+8 | 否 |

**注意**：上海/香港/青岛与旧金山时差：冬季16小时，夏季15小时

## 命令格式

| 命令 | 说明 |
|------|------|
| `find <参会城市> <时长> [偏好时段]` | 推荐最优会议时间窗口 |
| `convert <城市> <时间>` | 转换单个时间到其他城市 |
| `week <起始日期>` | 生成当周四城市时间对照表 |
| `block <会议描述> <时长>` | 生成会议邀请时间块（含多时区显示） |

## 可用时间窗口分析

适合四地参会的时间窗口（工作日）：
- **最优**：上海/港/青 20:00–22:00 = 旧金山 04:00–06:00（SF 早起）
- **次优**：上海/港/青 08:00–10:00 = 旧金山 16:00–18:00（前一日）
- **勉强可用**：上海/港/青 19:00 = 旧金山 03:00（需确认SF参与者接受）

## 输出格式

```
推荐时间：2026年6月15日（周一）
• 旧金山：6月14日(周日) 17:00 PDT
• 上海/香港/青岛：6月15日(周一) 08:00 CST
时长：60分钟
会议链接占位：[Zoom/Teams/腾讯会议]
```

## 日历文件导出

输出 `.ics` 格式，含多时区显示，可直接导入 Google Calendar / Outlook。
