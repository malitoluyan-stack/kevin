# Earnings Report — 财报解读

解读上市公司财报，提取关键指标，评估投资价值。使用 `$ARGUMENTS` 指定公司名称/股票代码和报告期。

## 格式：`<公司名/代码> <报告期：Q1/Q2/Q3/年报> [对比：YoY/QoQ] [视角：多头/空头/中立]`

## 解读框架

### 损益表（P&L）关键指标
- 营收增长率（YoY/QoQ）及增速趋势
- 毛利率变化及驱动因素（定价 vs 成本）
- 经营利润率（EBIT Margin）
- Non-GAAP 调整项目（识别一次性项目）

### 资产负债表健康度
- 现金及现金等价物（够几个季度运营？）
- 有息负债/EBITDA（杠杆水平）
- 存货周转天数（制造业关键）
- 应收账款质量（DSO变化）

### 现金流量表（最不会造假）
- 经营性现金流 vs 净利润（比值理想值 >1）
- 自由现金流（FCF = 经营CF - Capex）
- 资本支出趋势（扩张 or 收缩）

### 前瞻性指引
- 管理层下季度/全年指引（vs 市场预期）
- 关键业务KPI趋势（用户数/GMV/续费率等）

## 投资信号提示（仅供参考，非投资建议）

| 信号 | 含义 |
|------|------|
| FCF > 净利润且持续增长 | 盈利质量高 |
| 营收增长但现金流恶化 | 警惕应收账款 |
| 管理层连续下调指引 | 基本面恶化信号 |
| 回购+分红增加 | 管理层对前景有信心 |

**免责声明**：本分析仅为信息参考，不构成投资建议。投资决策请结合个人风险承受能力和专业顾问意见。
