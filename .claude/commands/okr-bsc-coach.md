# OKR-BSC Coach — OKR 与 BSC 方法论设计与对比

设计 OKR 或 BSC 体系，或对两种方法论进行对比分析。使用 `$ARGUMENTS` 指定场景。

## 模式

### `design-okr <团队/企业> <战略目标>`
输出季度 OKR：
- O（Objective）：激励性、方向性、非量化（3条以内）
- KR（Key Results）：可量化、有时限、挑战性但可达（每个O对应2–4条KR）
- 初始化项目（Initiatives）：驱动KR的具体行动

OKR 质量检查：
- KR是否可量化？（"提升满意度"→"NPS提升至X"）
- O是否激励性？（避免任务型O："完成X"→"成为X领域领导者"）
- KR之间是否互斥？（避免重复计算）

### `design-bsc <企业> <战略目标>`
输出平衡计分卡四维度：
- 财务：股东价值指标（ROE/EBITDA/收入增长）
- 客户：市场份额/NPS/客户留存
- 内部流程：运营效率/质量/创新速度
- 学习与成长：员工能力/文化/IT能力

### `compare <场景描述>`
对比两种方法论在该场景下的适用性：

| 维度 | OKR | BSC |
|------|-----|-----|
| 适用阶段 | 高速增长/创新 | 成熟企业/稳健经营 |
| 时间周期 | 季度 | 年度 |
| 指标数量 | 少而精（3O×3KR） | 全面（20–25个指标） |
| 向上传导 | 弱（自下而上为主） | 强（战略地图逐层分解） |
| 绩效连接 | 刻意脱钩 | 通常关联 |

给出明确推荐：在该场景下哪种方法论更适合，为什么。
