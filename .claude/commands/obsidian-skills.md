# Obsidian Skills

You have access to the user's Obsidian vault via the filesystem. Use it to:

- **Read notes** — find relevant notes by keyword or tag to inform your work
- **Create notes** — save outputs, summaries, or plans as new `.md` files in the vault
- **Update notes** — append to daily notes, add to MOCs (Maps of Content), or update project notes
- **Canvas** — describe or generate canvas JSON for visual thinking layouts

## How to use

When the user mentions a topic, search the vault for related notes first. Reference them by filename when relevant.

When producing a deliverable (summary, plan, code snippet), offer to save it as a note in the appropriate folder.

Vault path: ask the user for their vault path if not already known, then use filesystem tools to read/write `.md` files there.
