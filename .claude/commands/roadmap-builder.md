# Roadmap Builder — AI 实施路线图生成

生成分阶段、可执行的 AI 战略实施路线图。使用 `$ARGUMENTS` 指定企业背景和战略目标。

## 格式：`<企业名> <当前AI成熟度L1-L5> <战略目标> [时间跨度：12/24/36个月]`

## 路线图框架（三阶段）

### Phase 1：基础建设（0–6个月）
聚焦：数据治理 + 组织能力 + 快赢试点
- 里程碑：第一个 AI 用例上线，ROI 可量化
- 典型交付物：数据盘点报告、AI治理委员会成立、1个POC完成

### Phase 2：规模化推广（6–18个月）
聚焦：平台化 + 跨部门复制 + 能力建设
- 里程碑：3个以上业务线 AI 渗透，人均效率提升 X%
- 典型交付物：AI中台建设、内部培训体系、第二梯队用例

### Phase 3：AI原生转型（18–36个月）
聚焦：业务模式重塑 + 生态布局 + 竞争壁垒
- 里程碑：AI 成为核心竞争力，写入战略规划
- 典型交付物：AI产品/服务商业化、行业解决方案输出

## 每个里程碑包含

| 字段 | 内容 |
|------|------|
| 时间节点 | 具体季度 |
| 负责部门 | 主责+协同 |
| 所需资源 | 预算/人力/技术 |
| 成功指标 | 可量化KPI |
| 风险与应对 | 主要障碍+缓解措施 |

## 输出

路线图表格（可导入 PPT）+ 关键路径分析 + 资源优先级建议

配合 `/ai-maturity-assessment` 使用效果最佳。
