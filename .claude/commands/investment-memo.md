# Investment Memo — 投资决策备忘录

用第一性原理框架记录投资逻辑，强制写明假设和推导链。使用 `$ARGUMENTS` 指定投资标的。

## 格式：`<标的名称> <资产类型：股票/基金/REITs/加密/其他> <初始仓位建议>`

## 备忘录结构

### 1. 核心论点（1句话）
用一句话描述"为什么这个投资现在值得做"。若无法用一句话说清，说明论点不清晰。

### 2. 关键假设（必须显式列出）
列出支撑论点的3–5个核心假设，每个假设标注：
- **可验证性**：能否用数据/事件证伪？
- **时间跨度**：假设在多长时间内成立？
- **依赖条件**：该假设依赖哪些前提？

### 3. 推导链
```
假设A（数据来源）
  → 推论B（逻辑步骤）
    → 推论C
      → 结论：预期回报X%，时间跨度Y个月
```

### 4. 风险与反驳
主动列出3条最有力的反驳论点，并说明为何仍然成立。
不能反驳的风险：直接写"我不知道如何反驳，这是一个盲区"。

### 5. 退出条件（Pre-mortem）
预先定义止损/止盈条件：
- **止损**：哪些假设被证伪时卖出？
- **止盈**：预期目标达成时的行动？
- **时间止损**：持有X个月后若无进展？

### 6. 仓位建议
基于凯利公式或固定比例，说明仓位逻辑。

## 质量检查
- 是否有无法证伪的假设？（若有，标记为"信念"而非"假设"）
- 数据是否有来源？
- 是否有确认偏误（只找支持观点的证据）？
