# Citation Verifier — 引用核查与数据自洽检查

对咨询文档中的引用和数据执行严格核查。使用 `$ARGUMENTS` 指定文件路径或粘贴文本。

## 核查规则（零容忍项）

### 引用真实性
- 标记任何**无法验证来源**的报告标题（虚构引用特征：机构名+年份+具体数字，但无法检索到原文）
- 高信度来源白名单：Goldman Sachs、Citi Research、McKinsey Global Institute、BCG、Gartner、IDC、世界银行、IMF、国家统计局、卫健委
- 低信度来源警告：泛指"研究表明"、无年份、无页码的内部报告

### 数据自洽检查
- **加总验证**：分项数据之和是否等于总数（允许±0.1%舍入误差）
- **跨页一致性**：同一数据在不同页面的数值是否一致
- **口径统一**：对比数据是否使用相同口径（人均 vs 总量、CAGR vs 绝对值、人民币 vs 美元需标明汇率时间点）

### 推导逻辑
- 标记所有"因此/由此推断"类结论，检查其推导步骤是否完整
- 若推导跳跃，要求补充中间逻辑

## 输出格式

```
[引用问题] 第N页："[引用内容]"
风险级别：🔴 疑似虚构 / 🟡 来源不明 / 🟢 可验证
建议：替换为 [高信度替代来源] 或 删除

[数据问题] 第N页：分项合计 = X，但总数标注为 Y，差值 Z
建议：核查原始数据，统一口径
```

总结：虚构引用风险 N 处，数据不自洽 N 处，推导缺口 N 处。
