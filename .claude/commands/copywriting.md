# Copywriting

Write persuasive, conversion-focused copy. Use `$ARGUMENTS` to specify the type and context.

## Format: `<type> <product/service> [audience] [tone]`

### Copy Types

| Type | Output |
|------|--------|
| `headline` | 5 headline variations (problem/benefit/curiosity/social proof/direct) |
| `tagline` | 3 brand taglines (memorable, ≤8 words) |
| `landing-page` | Hero section + 3 benefit blocks + CTA |
| `email` | Subject line + preview text + body + CTA |
| `ad` | 3 ad variations (Facebook/Google/LinkedIn format) |
| `product-desc` | Features → benefits, 150–200 words |
| `social` | 3 posts for LinkedIn/Twitter/WeChat |
| `cta` | 5 CTA button/link text options |

## Copywriting Principles Applied

- **Clarity over cleverness**: reader understands in <5 seconds
- **Benefits not features**: "Save 3 hours/week" not "AI-powered scheduler"
- **Social proof**: include placeholder for testimonial/stat
- **One job per piece**: one message, one CTA
- **AIDA or PAS structure** for longer copy

## Output

All variations labeled and ready to A/B test. Include a note on which variation to test first and why.
