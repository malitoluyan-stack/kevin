# Tmux — 远程控制 tmux 会话

管理、查看和控制 tmux 会话、窗口和面板。使用 `$ARGUMENTS` 指定操作。

## 命令

### 会话管理
| 命令 | 说明 |
|------|------|
| `list` | 列出所有 tmux 会话 |
| `new <name>` | 创建新会话 |
| `attach <name>` | 附加到会话 |
| `kill <name>` | 关闭会话 |
| `rename <old> <new>` | 重命名会话 |

### 窗口/面板
| 命令 | 说明 |
|------|------|
| `windows <session>` | 列出会话中的窗口 |
| `split <session> [h\|v]` | 水平或垂直分割面板 |
| `send <session> <cmd>` | 向指定会话发送命令 |
| `capture <session>` | 捕获当前面板输出 |

### 工作区模板
| 命令 | 说明 |
|------|------|
| `workspace dev` | 创建开发工作区（editor + terminal + logs 三面板） |
| `workspace monitor` | 创建监控工作区（htop + logs + shell） |

## 行为

1. 解析 `$ARGUMENTS`
2. 对 `send` 和 `kill` 执行安全检查（见下方）
3. 执行对应 `tmux` 命令（使用 Bash 工具）

## `send` 命令安全协议

### 第一步：元字符检测
在展示确认前，扫描命令内容是否包含以下高风险模式：

| 模式 | 风险 | 处理 |
|------|------|------|
| `; &&` ` \|\| ` | 命令链接，可追加执行 | 🔴 警告 + 二次确认 |
| `$( )` `` ` `` | 命令替换 | 🔴 警告 + 二次确认 |
| `rm -rf` `dd if=` `mkfs` | 数据破坏 | 🔴 警告 + 二次确认 |
| `curl \| bash` `wget \| sh` | 远程代码执行 | 🔴 警告 + 二次确认 |
| `> /dev/` `chmod 777` | 系统级操作 | 🔴 警告 + 二次确认 |

检测到以上模式时，必须额外展示：「⚠️ 此命令包含高风险操作符，确认后将直接在会话中执行，无法撤销。」

### 第二步：强制确认展示
所有 `send` 操作均须展示：

```
tmux send 确认
━━━━━━━━━━━━━━━━━━━━
目标会话 : <session>
将执行命令: <cmd>
[如有风险标记]: ⚠️ <风险说明>
━━━━━━━━━━━━━━━━━━━━
确认执行？(yes/no)
```

用户输入 `yes`（全拼）方可执行，`y` 不被接受。

### `kill` 命令确认
同样要求输入 `yes` 全拼确认，并显示该会话当前运行的进程（通过 `tmux list-panes -t <session>` 获取）。

## 注意

`capture` 只读取输出，不向会话发送任何命令，无需确认。
