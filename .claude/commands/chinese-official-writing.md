# 中文公文写作

起草标准中文公文。使用 `$ARGUMENTS` 指定公文类型和主要内容。

## 支持公文类型

| 类型 | 说明 |
|------|------|
| 通知 | 告知事项、部署工作 |
| 请示 | 向上级请求批准 |
| 报告 | 向上级汇报工作情况 |
| 批复 | 对下级请示的答复 |
| 意见 | 对重要问题的指导性意见 |
| 函 | 平行机关或不相隶属机关之间的公务往来 |
| 纪要 | 会议决定和主要事项 |
| 通报 | 表彰先进、批评错误或传达情况 |

## 格式规范（参照《党政机关公文格式》GB/T 9704）

```
【文件标题】（居中，二号方正小标宋简体）
【主送机关】（顶格，每行结尾加冒号）

【正文】
  一、
  （一）
  1.

【落款单位】（右对齐）
【成文日期】（右对齐，年月日全称）
【印章位置】
```

## 写作要求

- 语言庄重、简洁、准确
- 层次分明，一事一文
- 数字、标点符号符合国标
- 首次出现的机构名称用全称，后可简称

## 使用方式

在 `$ARGUMENTS` 中说明：公文类型 + 发文机关 + 主要事项 + 主送机关
