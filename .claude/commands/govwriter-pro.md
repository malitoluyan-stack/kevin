# GovWriter Pro — 政府/官方文书写作

起草高质量政府报告、政策文件、申报材料和官方文书。使用 `$ARGUMENTS` 指定文书类型。

## 文书类型

| 类型 | 说明 |
|------|------|
| `年度工作报告` | 全年工作总结 + 下年计划 |
| `项目申报书` | 立项依据 + 目标 + 实施方案 + 预算 |
| `政策建议` | 背景 + 问题分析 + 政策建议 + 预期效果 |
| `调研报告` | 调研背景 + 基本情况 + 问题 + 对策建议 |
| `讲话稿` | 领导讲话/发言稿 |
| `新闻通稿` | 官方新闻发布稿 |
| `情况说明` | 专题情况报告 |
| `绩效报告` | 项目/部门绩效评估报告 |

## 写作规范

- 政治术语准确，符合当前政策导向
- 数据引用规范，标注来源
- 结构严谨：问题导向 → 现状分析 → 对策建议
- 语言风格：庄重务实，避免空话套话
- 量化表述：用具体数字代替模糊描述

## 使用方式

`$ARGUMENTS` 格式：`<文书类型> <主题/部门> <关键内容要点>`

示例：`年度工作报告 数字化转型办公室 完成3个系统上线，服务1200人次`
