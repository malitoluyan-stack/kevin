# Ad Creative — 广告创意生成

生成多平台广告创意方案。使用 `$ARGUMENTS` 指定产品/服务和目标受众。

## 格式：`<产品/服务> [平台] [受众] [核心卖点]`

## 支持平台

| 平台 | 输出内容 |
|------|---------|
| 微信朋友圈 | 图文广告（主图描述 + 文案 ≤40字） |
| 抖音/短视频 | 15秒脚本（钩子 + 冲突 + 解决 + CTA） |
| 小红书 | 种草笔记（标题 + 正文 + 标签） |
| 微博 | 140字内广告文案 + 话题标签 |
| B站 | 前贴片广告脚本（5秒不可跳过 + 30秒完整版） |
| Google/百度 | 搜索广告（标题×3 + 描述×2，字符限制内） |
| LinkedIn | 专业广告文案（针对B2B场景） |

## 创意框架（每套方案包含）

1. **核心洞察**：目标受众的真实痛点或渴望（一句话）
2. **创意概念**：广告的核心创意角度
3. **文案变体**：3个不同角度的文案（情感/理性/社会证明）
4. **视觉建议**：画面/场景描述（供设计参考）
5. **A/B测试建议**：哪个变体先测，为什么

## 中国市场特别说明

- 节日营销节点（双11/618/春节）自动适配
- 合规提示：避免极限用词（最、第一、绝对等）
- KOL/KOC 合作脚本版本可选
