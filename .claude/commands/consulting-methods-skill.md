# Consulting Methods Skill

Apply classic consulting frameworks to analyze a business problem. Use `$ARGUMENTS` as the topic or question.

## Available Frameworks

Specify a framework in `$ARGUMENTS`, or let Claude choose the best fit:

| Framework | Best for |
|-----------|----------|
| Porter's Five Forces | Industry attractiveness, competitive dynamics |
| Value Chain Analysis | Operational efficiency, cost/differentiation drivers |
| McKinsey 7S | Organizational alignment, change management |
| BCG Matrix | Portfolio prioritization (cash cows, stars, etc.) |
| SWOT | Quick situational overview |
| MECE | Structuring problems without overlap or gaps |
| Issue Tree | Breaking complex problems into hypotheses |
| Jobs-to-be-Done | Customer motivation and product fit |

## Behavior

1. Identify the business problem from `$ARGUMENTS`
2. Select the most appropriate framework (or use the one specified)
3. Apply it rigorously: fill in each component with relevant analysis
4. End with **So What** — 3 actionable implications

## Output

Use headers per framework component. Be concise and insight-driven, not descriptive.
