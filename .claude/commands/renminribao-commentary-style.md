# 人民日报评论文风 — People's Daily Commentary Style

按照人民日报任仲平文章、社论、钟声评论、人民时评的真实文风起草评论文章、政论或重大主题宣传稿。使用 `$ARGUMENTS` 指定文章类型和主题。

## 格式：`<类型：任仲平/社论/钟声/人民时评> <核心主题> [立论角度]`

---

## 四种文体特征

### 一、任仲平（重磅长篇政论，5000—8000字）

**结构模式**：
```
[引子：历史场景 或 时代设问]
第一部分：宏观定性（历史方位+形势判断）
第二部分：成就论证（数据+案例+排比）
第三部分：挑战直视（问题+根因+应对）
第四部分：路径展开（战略+举措+工程）
结语：召唤式排比 + 历史自信收尾
```

**标题样式**：
- 「[名词短语]的[历史/时代/中国]答卷」
- 「在[历史节点]把握[机遇/主动/方向]」
- 「[四字评价]的[XX年/时代/中国]」

**语言特征**：
- 宏观叙事+确凿数据+形象比喻+感人故事 四元素并举
- 极具场景感：「在XXX的土地上……」「走进XXX，你会看到……」
- 善用对比：「曾经……如今……」「过去……现在……」
- 排比气势：三段式或四段式排比，每段60—100字，内部自成逻辑
- 警句密度高：每1000字至少2条可独立传播的金句

**禁忌**：
- 避免流水账式罗列（必须有叙事弧度）
- 不直接抨击，用「历史的镜子」「国际比较」侧面论证

---

### 二、人民日报社论（权威短评，800—1500字）

**结构模式**：
```
第一段：定性锚定（「这是……的重要时刻」）
第二段：成就陈述（数据支撑，2—3条）
第三段：意义阐释（历史意义+现实意义）
第四段：任务部署（「我们要……」排比）
结尾：信心宣示
```

**标题样式**：「[动词][对象]，[成就]新[局面/篇章/格局]」

**特征**：
- 旗帜鲜明，立场明确，无歧义空间
- 句式短促有力：四字—六字—八字混搭
- 数据精确：必须标注来源部门（国家统计局/相关部委）

---

### 三、钟声（国际评论，1000—2000字）

**定位**：针对国际社会误解、西方批评的有理有节回应

**结构模式**：
```
[引子：对方论点的简要呈现]
[我方立场：一句话定性]
[反驳论据：3条，数据+事实+国际规范]
[升华：中国道路的普遍价值]
[结语：开放合作呼吁]
```

**语气**：自信而不傲慢，有理有据，留有余地不失原则

---

### 四、人民时评（轻评论，800—1200字）

**定位**：贴近读者、话题感强的政策解读与价值引导

**特征**：
- 从具体事件/故事切入，再上升到政策层面
- 语气相对亲切，可用反问、设问
- 结尾留白式：提出问题供读者思考，不强行收束

---

## 核心词汇库

### 历史定性
历史交汇期、时代答卷、关键节点、历史性跨越、深刻变革、百年未有之大变局、中华民族伟大复兴的历史进程

### 成就叙述（比喻型）
绘就了一幅……的壮美画卷、书写了……的崭新篇章、创造了……的人间奇迹、跑出了……的加速度

### 数据引入句式
「数字是最有力的证明。[数字1]……[数字2]……[数字3]……这一组数字的背后，是……」

### 人民主体表达
「人民群众是历史的创造者」、「把人民对美好生活的向往作为奋斗目标」、「让发展成果更多更公平惠及全体人民」

### 挑战正视句式
「我们也要清醒认识到，[问题表述]。这些问题，有的是……积累的历史欠账，有的是……带来的新挑战，需要我们……」

### 号召结语排比式
```
让我们[动词短语]，
在[领域]上[成就表述]，
在[领域]上[成就表述]，
在[领域]上[成就表述]，
共同谱写[高质量修饰语]的新篇章！
```

### 任仲平标志性开篇意象
- 时间意象：「历史的时针走到……」「时间是最忠实的记录者」
- 空间意象：「在这片960万平方公里的土地上……」
- 设问意象：「什么是……？……就是……」
- 对比意象：「站在[高度]俯瞰，[景象1]；走进[近处]，[景象2]」

---

## 质量检查清单

- [ ] 是否有宏观定性句（历史方位锚定）
- [ ] 数据是否有来源标注（或明确说明「国家统计局数据」）
- [ ] 是否至少有一处场景化描写（增加画面感）
- [ ] 排比段是否内部逻辑自洽（各段间不重复、有递进）
- [ ] 是否有1—2条可独立传播的金句
- [ ] 结语是否有召唤感（而非平淡收尾）
- [ ] 全文有无「一定成绩」「很多工作」等空洞表述（须删除）

## 与其他文风的对比定位

| 文风 | 核心气质 | 长度 | 适用场景 |
|------|---------|------|---------|
| 任仲平 | 宏大、精致、厚重 | 5000—8000字 | 重大节点政论、战略宣示 |
| 社论 | 权威、简练、鲜明 | 800—1500字 | 重要会议/决策配套评论 |
| 钟声 | 理性、自信、有礼 | 1000—2000字 | 国际议题回应 |
| 人民时评 | 亲切、贴近、引导 | 800—1200字 | 社会热点价值引导 |
| 政府工作报告 | 务实、数据、部署 | 8000—15000字 | 年度工作总结部署 |
| 五年规划 | 系统、结构、目标 | 15000—30000字 | 中长期战略规划 |

配合 `/gov-work-report-style`、`/five-year-plan-style`、`/xi-new-year-address-style` 使用可覆盖全类型政务与政论写作。
