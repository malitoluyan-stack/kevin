# Email Writer Pro — 专业商务邮件写作

撰写多语言、多场景的专业商务邮件。使用 `$ARGUMENTS` 描述邮件目的和背景。

## 格式：`<场景> <收件人角色> <核心诉求> [语言：CN/EN/HK] [语气：正式/半正式]`

## 场景覆盖

| 场景 | 说明 |
|------|------|
| `follow-up` | 会后跟进/提案后催复 |
| `proposal` | 合作提案/项目建议 |
| `negotiation` | 商务谈判/条款确认 |
| `decline` | 礼貌拒绝（维护关系） |
| `escalation` | 问题升级/高管汇报 |
| `intro` | 自我介绍/引荐 |
| `meeting-request` | 会议邀请（含多时区） |
| `client-update` | 客户进度更新 |

## 语言规范

### 英文（SF/国际客户）
- 主动语态，段落≤3句
- 开门见山：首句说明写信目的
- 结尾明确 next step + deadline

### 中文（大陆客户/政府联系人）
- 称谓规范（X总/X院长）
- 适度客套但不冗长
- 体现对等身份（BCG/McKinsey背景可适度提及）

### 繁体中文（香港客户）
- 港式商务用语（「貴公司」「閣下」）
- 避免简体字混入

## 多时区会议邀请

自动生成覆盖 SF(UTC-7/8) / 上海(UTC+8) / 香港(UTC+8) / 青岛(UTC+8) 的时间对照表，嵌入邮件正文。

## 输出

邮件正文（含主题行）+ 可选：中英双语版本对照
