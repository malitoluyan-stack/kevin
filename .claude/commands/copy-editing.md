# Copy Editing

Edit and improve the provided text for clarity, grammar, style, and flow. Use `$ARGUMENTS` as the text or file path.

## Editing Levels

Specify in `$ARGUMENTS` or Claude will choose based on the text:
- `light` — fix grammar/spelling only, preserve voice
- `standard` (default) — grammar + clarity + flow + word choice
- `heavy` — restructure sentences, improve argument logic, sharpen language

## What gets fixed

- Grammar and spelling errors
- Passive voice → active (where appropriate)
- Vague language → specific
- Redundant words and filler phrases removed
- Sentence variety (mix short and long)
- Paragraph transitions
- Inconsistent terminology or tone

## Output Format

Provide:
1. **Edited version** — clean, ready-to-use text
2. **Change summary** — bullet list of key changes made
3. **Notes** — any structural issues the editor couldn't fix inline (e.g., "Section 2 contradicts Section 4")

## For Chinese text
Apply equivalent Chinese editorial standards: 去除口语化表达、统一标点、修正病句、调整句序。
