# Strategic Diagnosis Frameworks

Diagnose a strategic situation using structured frameworks. Use `$ARGUMENTS` as the business context or question.

## Diagnosis Frameworks

### Problem Structuring
- **Issue Tree**: break the problem into MECE hypotheses
- **5 Whys**: drill to root cause
- **Hypothesis-driven**: state hypothesis, test, conclude

### Strategic Position
- **Rumelt's Good Strategy/Bad Strategy**: kernel = diagnosis + guiding policy + coherent actions
- **Playing to Win**: winning aspiration → where to play → how to win → capabilities → management systems
- **Blue Ocean**: eliminate-reduce-raise-create grid

### Competitive Dynamics
- **Competitive Moat Assessment**: network effects, switching costs, cost advantages, intangibles, efficient scale
- **Disruption Analysis**: is the threat sustaining or disruptive? low-end or new-market?

## Behavior

1. Identify the type of strategic question from `$ARGUMENTS`
2. Select 1–2 most relevant frameworks
3. Apply rigorously with specific observations
4. Produce a diagnosis (what is really going on) + recommended strategic direction

## Output

Diagnosis in plain language + framework output + 3 strategic options with trade-offs.
