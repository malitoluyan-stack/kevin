# Campaign Plan

Create a full marketing campaign plan for `$ARGUMENTS` (product launch, event, promotion, or goal).

## Plan Structure

1. **Campaign Brief**
   - Objective (SMART goal)
   - Target audience (primary + secondary persona)
   - Key message (one sentence)
   - Budget range

2. **Channel Mix**
   - Recommended channels with rationale (paid, owned, earned)
   - Budget allocation % per channel

3. **Content Calendar** (4-week sprint)
   | Week | Channel | Content Type | Message | CTA |
   |------|---------|-------------|---------|-----|

4. **Creative Direction**
   - Visual tone and style
   - Copy angle and voice
   - Key visual/hook concept

5. **KPIs & Measurement**
   - Primary KPI (e.g., conversions)
   - Secondary KPIs (reach, CTR, CAC)
   - Measurement cadence

6. **Launch Checklist**
   - [ ] Tracking set up
   - [ ] Creative approved
   - [ ] Landing page ready
   - [ ] Budget allocated

## Behavior

Parse `$ARGUMENTS` for product/service, target market, timeline, and budget. Ask for any missing critical info before generating the plan.
