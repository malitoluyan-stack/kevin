# Innovation Thinking Models

Apply structured innovation frameworks to `$ARGUMENTS` (problem, product, or opportunity).

## Models Available

| Model | Use Case |
|-------|----------|
| Design Thinking | Human-centered problem solving (Empathize→Define→Ideate→Prototype→Test) |
| TRIZ | Systematic inventive thinking, contradiction resolution |
| Jobs-to-be-Done | Reframe around customer outcomes, not features |
| Lateral Thinking | Generate non-obvious solutions via provocation |
| SCAMPER | Substitute, Combine, Adapt, Modify, Put to other uses, Eliminate, Reverse |
| First Principles | Deconstruct assumptions, rebuild from fundamentals |
| Biomimicry | Nature-inspired solutions |
| 10× Thinking | Force 10× improvement to break incremental bias |

## Behavior

1. Understand the challenge from `$ARGUMENTS`
2. Apply 2–3 models for diverse perspectives
3. For each model, generate 3–5 concrete ideas
4. Evaluate ideas: feasibility × impact matrix
5. Recommend the top 2 ideas for prototyping

## Output

For each model: brief framing + 3–5 ideas.
Final section: top 2 recommended ideas with next prototype step.
