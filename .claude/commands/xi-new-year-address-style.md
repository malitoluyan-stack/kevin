# 习近平新年贺词文风 — Xi Jinping New Year Address Style

按照习近平历年新年贺词（2020—2026年）的真实文风起草讲话稿、致辞或新年寄语。使用 `$ARGUMENTS` 指定受众和主题。

## 格式：`<受众：全国/党员/企业员工/行业> <主题词> [年份/生肖]`

---

## 文体特征（必须严格遵守）

### 标准段落结构

```
[开篇：定位时空 + 亲切称呼]
[回顾段：一年成就 + 数字罗列]
[感念段：人民群众 + 基层故事]
[挑战段：问题正视 + 信心表达]
[展望段：来年目标 + 排比期许]
[结语：生肖意象 + 四字祝福]
```

### 开篇句式模板

```
大家好！[时间定语]，又是新的一年。我在[地点]向大家致以美好的祝福！
```

示例（2026）：「大家好！岁月常新，又是新的一年。我在北京向大家致以美好的祝福！」

### 成就罗列句式（数字+成就配对）

```
[领域]实现[量化成果]，[领域]取得[历史性突破]，[群体]的[生活维度]持续改善。
```

示例：「经济总量突破XX万亿元，粮食产量再创历史新高，城乡居民收入稳步提升。」

**禁止**虚构数据；如无确切数字，用「显著提升」「持续改善」等定性描述。

### 感念基层句式（排比三段式）

```
我[动作]了[地点/群体]的[人物]，他们[具体行为]；
我[动作]了[地点/群体]的[人物]，他们[具体行为]；
……
他们的[精神品质]，让我[情感反应]。
```

示例：「我看到了环卫工人在凌晨默默清扫的身影，看到了科研人员在实验室彻夜攻关的执着，看到了志愿者在灾难现场奋勇逆行的担当。每一个普通人，都是这个时代的英雄。」

### 排比期许句式（来年展望）

**三段排比式**：
```
让我们[动词+四字短语]的勇气，
激发[四字短语]的活力，
保持[四字短语]的干劲。
```

示例（2026马年）：「让我们拿出跃马扬鞭的勇气，激发万马奔腾的活力，保持马不停蹄的干劲，把宏伟愿景变成美好现实！」

**梦想-奋斗式**：
```
梦虽遥，追则能达；
愿虽艰，持则可圆。
```

### 结语祝福模板

```
祝愿大家[四字×2]，[四字×2]！
祝愿祖国[四字×2]，[四字×2]！
[生肖年份]快乐！
```

## 核心词汇库

### 成就叙述
踔厉奋发、勇毅前行、克服重重困难挑战、圆满完成目标任务、实现历史性跨越、交出亮丽答卷、书写崭新篇章

### 人民情感
每一个人都是主角、每一份付出都弥足珍贵、每一束光芒都熠熠生辉、人民群众的获得感幸福感安全感、念兹在兹

### 奋斗意志
砥砺前行、不懈奋斗、接续奋斗、赓续奋斗、初心不改、使命在肩、众志成城、同舟共济

### 生肖动物意象库（按年份）
| 生肖 | 意象词组 | 排比动词 |
|------|---------|---------|
| 马（2026） | 跃马扬鞭、万马奔腾、马不停蹄、龙马精神 | 驰骋、奔腾、扬蹄 |
| 蛇（2025） | 灵蛇献瑞、祥蛇纳福 | — |
| 龙（2024） | 龙腾虎跃、龙马精神、腾飞 | 腾飞、翱翔 |
| 兔（2023） | 玉兔迎春、奋兔争先 | — |

### 古诗引用规律
- 引用须契合主题，不堆砌
- 常用句式：「正如古人所云，"[诗句]"。[联系当代意义]。」
- 2025年示例：「"雄关漫道真如铁，而今迈步从头越。"」（豪迈奋进时引用）
- 2024年示例：「"千里之行，始于足下。"」（强调实干时引用）

## 语气与分寸

| 维度 | 要求 |
|------|------|
| 人称 | 第一人称「我」+集体「我们」交替；拉近距离 |
| 情感 | 温暖、真诚、亲切，不煽情、不说教 |
| 问题正视 | 「我们也清醒认识到」「前进道路上还有不少困难和挑战」——必须有，体现真实 |
| 篇幅 | 800—1200字；段落5—8个；不超过10段 |
| 用语 | 口语化+政治术语平衡；避免纯学术或纯白话 |

---

## 禁用表达

- ❌ 「我们做了很多工作」（须具体化）
- ❌ 任何英文缩写（GDP须说「国内生产总值」首次出现时）
- ❌ 空洞的「再创辉煌」「更上一层楼」（须配合具体方向）
- ❌ 虚构引用或捏造数据

---

## 输出格式

完整贺词草稿（800—1200字），含：
1. 开篇定位句
2. 年度成就段（含数字或定性描述）
3. 人民群众感念段（含1—2个具体群体意象）
4. 困难挑战正视段
5. 来年展望排比段
6. 生肖意象结语+四字祝福

配合 `/gov-work-report-style`、`/five-year-plan-style` 使用可形成完整政务文书体系。
