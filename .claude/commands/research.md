# Research — 网络调研与信息提取

让 Claude Code 变成调研助手：网络搜索、资料研究、数据对比、趋势分析、报告生成。

## 命令格式

| 命令 | 说明 |
|------|------|
| `search <query>` | 网络搜索并综合多源信息 |
| `extract <url> <what>` | 从指定页面提取特定信息 |
| `compare <A> vs <B>` | 对比分析两个事物 |
| `trends <topic>` | 分析话题趋势和发展方向 |
| `report <topic>` | 生成结构化调研报告 |
| `scrape <url> <pattern>` | 批量抓取页面数据 |
| `cite <claim>` | 为某个论断寻找权威引用 |

## 调研流程

1. **广度搜索**：用 WebSearch 搜索 3–5 个角度
2. **深度阅读**：对重要源用 WebFetch 读取全文
3. **交叉验证**：多源核对关键数据
4. **结构化输出**：按报告格式整理

## 报告结构

```
# [主题] 调研报告
日期：[date] | 信息截止：[date]

## 核心发现（3 bullet）
## 详细分析
## 数据与来源
## 结论与建议
## 参考链接
```

## 数据提取

结合 Playwright MCP（`/agent-browser`）可抓取动态页面数据，结合 `/excel-xlsx` 可直接导出为表格。
