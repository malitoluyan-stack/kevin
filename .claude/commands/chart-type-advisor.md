# Chart Type Advisor — 图表选型顾问

根据数据关系和表达意图，推荐最匹配的图表类型。使用 `$ARGUMENTS` 描述数据或粘贴数据结构。

## 选型逻辑矩阵

| 表达意图 | 推荐图表 | 避免使用 |
|---------|---------|---------|
| **组成**（部分与整体） | 饼图（≤5类）/ 堆叠柱图（多时期） | 折线图 |
| **排序**（大小对比） | 水平条形图（类别多）/ 垂直柱图（类别≤7） | 饼图 |
| **时间趋势** | 折线图（连续）/ 柱图（离散期间）| 饼图 |
| **相关性** | 散点图（两变量）/ 气泡图（三变量）| 柱图 |
| **分布** | 直方图 / 箱线图 | 折线图 |
| **地理** | 地图（Choropleth）| 饼图 |
| **多维对比** | 雷达图（≤8维，SPAN模型适用）/ 热力图 | 折线图 |

## BCG 视觉规范（输出时自动应用）

- 主色：深蓝 `#003366` + 强调绿 `#00A651`
- 字体：微软雅黑（中文）/ Calibri（英文数字）
- 数据标签：显示在柱/线上方，不使用图例（直接标注系列名）
- 网格线：仅水平浅灰虚线，无边框

## 行为

1. 解析 `$ARGUMENTS` 中的数据结构和表达目标
2. 推荐首选图表类型 + 备选方案（含选择理由）
3. 若现有图表类型错误，说明错误原因
4. 输出对应的 Python（matplotlib/plotly）或 pptxgenjs 代码片段
