# Coding Agent — 编码任务代理

以自主 Agent 模式完成编码任务：分析需求、制定方案、编写代码、运行测试、修复错误。使用 `$ARGUMENTS` 描述任务。

## 配置（可选增强）

```bash
# 使用 OpenAI Codex（已弃用，现用 GPT-4）
export OPENAI_API_KEY=<key>

# 使用 Claude Code CLI（当前环境已内置，无需额外配置）
```

## 工作流

### 1. 需求分析
- 解析 `$ARGUMENTS` 中的任务描述
- 识别：语言/框架、输入/输出、约束条件
- 如不明确，提问澄清（最多 3 个问题）

### 2. 方案规划
- 列出实现步骤
- 识别需要创建/修改的文件
- 估算复杂度（S/M/L）

### 3. 编码执行
- 逐步实现，每步完成后自测
- 遵循项目现有代码风格
- 不引入不必要的依赖

### 4. 验证
- 运行相关测试（如存在）
- 对关键路径进行手动验证
- 检查边界条件

### 5. 交付
- 总结变更内容
- 列出遗留问题或后续建议

## 模式

| 参数 | 说明 |
|------|------|
| `--dry-run` | 只规划，不执行 |
| `--test-first` | TDD 模式：先写测试再实现 |
| `--no-confirm` | 跳过确认直接执行（谨慎使用） |
