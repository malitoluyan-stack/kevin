# 政府工作报告文风 — Chinese Government Work Report Style

按照中国政府工作报告（国务院/省政府/市政府）的标准文风起草或改写文稿。使用 `$ARGUMENTS` 指定报告类型、汇报主体和主要内容。

## 格式：`<层级：国/省/市/区县> <汇报单位> <报告年份> <核心工作内容>`

---

## 文体特征（必须严格遵守）

### 结构规范
```
一、[年度工作回顾]（过去一年主要成就，数据支撑）
二、[存在的困难和问题]（客观承认，不回避）
三、[下一年度工作安排]（分领域部署，有具体目标）
```

国务院级报告惯用三段式；省市级可扩展为五至八个部分。

### 语言特征

**开篇套语（按层级选用）**：
- 国务院：「各位代表：现在，我代表国务院，向大会报告政府工作，请予审议，并请全国政协各位委员提出意见。」
- 省级：「各位代表：现在，我代表省人民政府，向大会报告工作，请予审议，并请省政协委员和其他列席人员提出意见。」

**数字表达规范**：
- 经济数据用「增长X%」「达到X亿元」「新增X万个」
- 成就表述：「圆满完成」「超额完成」「取得重大突破」「实现历史性跨越」
- 问题表述：「仍面临不少困难」「还存在一些突出问题」「与人民群众期待还有差距」

**动词搭配规范**：
- 工作部署：「深入推进」「扎实推进」「统筹推进」「加快推进」「有序推进」
- 政策落实：「切实落实」「认真落实」「全面落实」「狠抓落实」
- 目标设定：「确保完成」「力争实现」「争取突破」

**禁止使用**：
- 「我们做了很多工作」（需具体化）
- 「取得了一定成绩」（需数据支撑）
- 任何英文缩写或互联网用语
- 第一人称单数「我」（应为「政府」「我们」）

### 数据引用要求
- 所有数字必须有统计来源（国家统计局/省统计局/行业主管部门）
- 同一数据在全文保持一致
- 增速、总量、结构三类数据搭配使用

### 政治表述规范
- 党的领导置于首位：「在以习近平同志为核心的党中央坚强领导下」
- 重大工作需对应政策依据（如：「深入贯彻党的二十届三中全会精神」）
- 涉及国家战略需准确引用：「高质量发展」「中国式现代化」「新质生产力」

---

## 分领域写作模板

### 经济发展
「全年地区生产总值达到X亿元，增长X%，高于/低于全国/全省平均水平X个百分点。」

### 民生保障
「城镇新增就业X万人，城镇调查失业率控制在X%以内。居民人均可支配收入增长X%。」

### 科技创新
「研究与试验发展经费投入强度达X%，高新技术企业达到X家，技术合同成交额X亿元。」

---

## 输出格式

完整报告草稿（含开篇、正文、结语），标注各段字数建议（国务院级全文约15,000字，省级约10,000字，市级约8,000字）。

配合 `/govwriter-pro` 和 `/chinese-official-writing` 使用效果最佳。
